# FAQ

## General

**Q: Is the data real?**
No. Every number in `data/synthetic/` is generated by
`voxfrontier.data.synth` from a fixed seed. The generator mimics the *shape*
of a real study (field structure, magnitudes, planted U-valleys and
thresholds) but contains **no real streamers, rooms, audio, or platform
records**. See README → *Data & privacy*.

**Q: Can I connect my own dataset?**
Yes, if you hold the rights to it: point `paths.data_dir` in a config YAML
at a local CSV matching the schema in `voxfrontier/data/schema.py`.
Keep it out of git (`.gitignore` already excludes it).

**Q: Why DEA and not SFA / free-form hull?**
DEA needs no functional-form assumption on the production frontier and is
the standard first tool for small-to-moderate cross-sections; the pipeline
complements it with parametric second-stage models (Tobit, DML). Adding an
SFA module is a welcome contribution — open a feature request with a
reference.

**Q: Why is Shapley so slow?**
Exact Shapley over *k* groups solves 2^k − 1 LPs. The default grouping keeps
k small (guard rail `attribution.shapley_max_vars`); the pipeline finishes
in ~1 minute end-to-end.

## Methods

**Q: What exactly does the DML stage estimate?**
The debiased partial effect of each voice variable on efficiency, using
cross-fitted Neyman-orthogonal scores (Chernozhukov et al. 2018). It is an
associational estimator that removes confounding **linearly represented in
the controls you provide** — it is not a magic causal identifier; see
`docs/methodology.md` §5 for assumptions.

**Q: Why both Tobit OLS-style and MLE?**
The OLS-style two-limit model matches the original study's workflow; the
MLE proper is the statistically efficient estimator under censoring.
Reporting both makes the difference visible.

**Q: Are the bootstrap p-values exact?**
No bootstrap test is exact; the threshold stage uses the Hansen-style
fixed-X bootstrap because the LR statistic under a threshold has a
non-standard distribution. Coverage is validated on synthetic ground truth.

**Q: What guarantees do conformal intervals have?**
Marginal coverage ≥ the nominal level (e.g. 90%) under exchangeability,
independently of model correctness — validated in tests on fresh draws.

## Operations

**Q: scipy vs PuLP backend — which should I use?**
Default `scipy` (HiGHS): faster install, fewer moving parts. Use `pulp`
(CBC) if you need exact MILP semantics or hit an LP edge case. Backends are
equivalence-tested.

**Q: The manifest verification failed. What now?**
Some output file changed after the run (manual edit, partial re-run).
Re-run `vxf run-all`; if it persists, check for concurrent processes
writing into `output/`.

**Q: How do I cite this?**

in the README.
